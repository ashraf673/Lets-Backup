# Let's Backup

**Portable · Verified · Lossless** photo and video backup for Android.

## Version 1.2 – Build 4 (Final)

### Complete Features

**Backup**
- Media scan, album / date / type selection
- Destination folder (Internal / SD / USB)
- Real `.lb.zip` (lossless, SHA-256, manifest)
- Progress + incomplete backup detection

**Restore**
- Detect valid archives
- Choice: Original locations OR Dedicated folder
- Automatic Replace
- Progress display

**UI (Build 4)**
- Clean Apple / One UI inspired design
- LB logo
- Ashraf Creation watermark (normal + large during progress)
- Dark / Light / System theme switch
- Bug Report (logs) button

### Theme
Tap **Theme: System** on the home screen to cycle:
- System → Light → Dark
